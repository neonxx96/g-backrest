# Задача 007: Архитектурный адаптер ChartEngine + Профессиональный Footprint & Liquidity Terminal (ATAS + CScalp + Coinglass)

## 🎯 1. Цель задачи
Превратить графический стек терминала в высокопроизводительную платформу анализа ликвидности и потока ордеров (уровня **ATAS, TigerTrade, CScalp и Coinglass**) на базе многослойного сэндвича (`KLineCharts v9` + `Canvas 2D` + `WebGL`), изолированного через единый адаптер `ChartEngine`, с сохранением плотностей для будущего алготрейдинга.

### Ключевые блоки реализации:
1. **Адаптер `ChartEngine` (Изоляция библиотеки):**
   - Единый интерфейс приложения: `setHistory`, `updateBar`, `setTheme`, `priceTimeToCoord`, `coordToPriceTime`, `subscribeViewportChange`, `getVisibleRange`, `resize`, `destroy`.
   - Изолированная реализация `KLineChartsV9Adapter` для установленной версии `klinecharts@9.8.12`. Никакой привязки внешних компонентов к методам библиотеки.
   - Полная совместимость со всеми существующими оверлеями (бэктест-сделки, сигналы, линейки, R:R Box, алерты).
2. **Единая тёмная тема терминала:**
   - Свечи, сетка, шкалы цен/времени, перекрестие (crosshair) и панели индикаторов приводятся к общей палитре терминала (`#0a0d14`, `#1f2638`, фирменные акценты).
3. **On-Chart DOM (Стакан у ценовой шкалы, референс 2):**
   - Горизонтальная гистограмма плотностей L2 прямо у правой границы ценового графика.
   - Настройки: длина вылета (px), прозрачность, цвета bids/asks.
4. **Квант-слой плотностей для Алготрейдинга (`LiquidityWallStore`):**
   - Структурированное отслеживание крупных лимитных стенок: `{ price, side, volumeUsd, depthShare, firstSeenTs, lifetimeSec, spoofScore, isTested }`.
   - Доступность данных для алгоритмических стратегий (отскок от стенки, защита от пробоя, снятие спуф-заявок).
5. **Canvas Footprint & Naked POC (референсы 3 и 4):**
   - Отрисовка кластеров на Canvas 2D поверх свечей (никаких React DOM-нод на уровень цены!).
   - Столбцы Bid x Ask, дельта, подсветка POC свечи.
   - Автоматическое продление непокрытых уровней POC (Naked POC) вправо до теста ценой.
   - Плашка с суммарной дельтой и объёмом под каждой свечой (`Delta -291.96K`, `Total 2.78M`).
   - Механизм **Level of Detail (LOD)**: скрытие чисел при отдалении масштаба (только цветные полосы) и показ моноширинного текста при приближении.
   - Честное состояние «нет тиковых данных» при отсутствии ленты тиков (без псевдо-кластеров из OHLCV).
   - Замер времени кадра через `performance.now()`.
6. **Скальперский стакан CScalp-уровня (`OrderBookCanvasLadder`, референс 5):**
   - Выделение крупных сайзов ($1M+, $500K+, $100K+) с процентом от среднего стакана.
   - Таймер «времени жизни» плотности (секунды/минуты удержания заявки).
   - Детектор спуфинга (сигнализация при резком снятии стенки перед ценой).
   - Пузыри крупных рыночных сделок (Trade Bubbles) рядом со стаканом.
7. **Карта ликвидаций (Liquidation Heatmap, референс 1):**
   - Фоновый WebGL-шейдер за свечами на базе расчета ликвидационных пулов по плечам (10x, 25x, 50x, 100x).
   - Настраиваемые палитры (`Magma`, `Sunset`, `Viridis`), слайдеры прозрачности и размытия.
8. **Бенчмарк и вердикт:**
   - Замер FPS и расхода памяти. Окончательный вывод: остаёмся на KLineCharts v9 или требуется замена бэкенда свечей.

  - Подсветка POC и авто-продление линий Naked POC.
  - Табличка Delta / Total под баром.
  - Механизм LOD (скрытие текста при сжатии масштаба).
  - Отображение статуса «Нет тиковых данных» при отсутствии ленты.

  - Детектор спуфинга (красная вспышка при отмене).

### Этап 6: Бенчмарк и финальный вердикт
- Замерить FPS при полной нагрузке (Footprint + DOM + Heatmap + Liquidations).
