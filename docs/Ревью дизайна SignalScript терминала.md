## Главные проблемы

### 1. Верхняя панель перегружена

Сверху одновременно идут логотип, тикер, поиск, таймфреймы, переключатель COIN/USDT/USDC, AI-бейдж, кнопка «+ Виджеты», раскладки, Replay, Бэктест, DOM, Лента, Сигналы, Слой стен, Карантин, BBG, а также ряд Layers и ряд раскладок. Получается четыре полоски инструментов, и все кнопки выглядят одинаково важными. Нужна иерархия: основное (тикер, таймфрейм, режим) отдельно, второстепенное в меню или по hover.

### 2. Тулбар графика смешивает стили

Одни кнопки залиты (оранжевая, зелёная, красная, синяя), другие просто контуры, третьи текст. Цвет означает разное: то статус, то тип слоя, то просто акцент. Нужен один стиль: нейтральные кнопки, а цвет только у активного состояния, причём один акцентный цвет на включённый слой.

### 3. Оверлеи перекрывают график

Плашка с BUY LIMIT / SL / TP1 / TP2 и карточка «FLAT» закрывают верхнюю часть графика и шкалу цен. Сама плашка слишком кричащая: четыре насыщенные заливки на одной строке спорят со свечами. Такие данные лучше держать в одном компактном блоке с тонким бордером.

### 4. Подписи уровней забивают график

Строки вида «SPOT WALL 415532.05 (7.75x)» и суммы «$4.05M (25x)» идут почти на каждый уровень. Справа они налезают друг на друга (ASK WALL, BID WALL, $3.67M, $3.55M). Нужны группировка близких уровней, показ подписей только для top-N или по hover, и сокращение формата (например, $4.1M без повтора плеча, плечо в tooltip).

### 5. Цвета без системы

Есть бирюзовый, красный, золотой, синий, фиолетовый, оранжевый, и почти все передают разный смысл. Задача — монохромная, спокойная эстетика с ярким акцентом только для важного (сигналы, ликвидации). Палитру нужно разложить на токены.

### 6. Типографика и контраст

Много подписей 9–10px серым на почти чёрном фоне: «Претенденты обновляются...», подписи в KPI, заголовки таблиц. Минимум — 11px для подписей и 12px для чисел. Моноширинный шрифт держать только для цифр.

### 7. Баги, видимые на скриншотах

- В AI-ассистенте сырой markdown: `**#AVAXUSDT**` выводится со звёздочками.
- В блоке «Консилиум» видны технические теги VETO\_RR\_TOO\_LOW и «ВЕТО: КАРАНТИН ЗАБЛОКИРОВАН». Пользователю нужен понятный текст, код можно оставить в tooltip.
- Обрезаны подписи: «КЛАСТЕР (BID×ASK)» в шапке DOM, «Лента сд» в заголовке ленты, «Цен» у правого края.
- Кнопка «Сброс $100» стоит рядом с красной EMERGENCY STOP. Деструктивные действия лучше разнести, а для аварийной кнопки добавить подтверждение.

### 8. Смешение языков и иконок

Заголовки то русские, то английские («Chart (График)», «Biggest Short Level», «Win rate», «Profit Factor»). В AI-панели стоят эмодзи (🚀 ⚡ 🏆 📊 🛡️ 🎯) рядом с иконками lucide. Нужен один язык интерфейса и один набор иконок (lucide), эмодзи убрать.

### 9. Лишние пустые зоны

В левой панели большие пустые блоки с иконкой-заглушкой («Нет активных лимитных заявок»). Пустые состояния можно сделать одной строкой, а освободившееся место отдать таблице или графику.

## Что уже хорошо

- **Окно «Центр настроек»**: самое аккуратное место интерфейса. Вкладки, сегменты, поля с подписями, понятные кнопки в футере. Хороший шаблон для остальных модалок.
- **Меню «Модули & Виджеты»**: компактно, горячие клавиши справа. Такой же паттерн подойдёт для тулбаров.
- **Красный баннер «НЕ ТОРГОВАТЬ / БЛОКИРОВКА»** в бэктесте: состояние сразу видно, иерархия предупреждения правильная.
- **KPI-карточки** с крупным значением и мелкой подписью в бэктесте и трейд-истории читаются хорошо.

## Замечания к CLAUDE\_SHADCN\_DESIGN\_SPEC.md

- Сначала сделать токены (цвета, радиусы, размеры, типографика, 3 пресета темы), и только потом менять компоненты. Иначе миграция на shadcn перепишет визуал дважды.
- Пресетов оставить три, а не три сложные темы (tealstreet, tiger, bloomberg), у которых отличается не только цвет, но и разметка.
- В спеке указаны 611 pytest, а в последних отчётах агентов 84–86. Стоит перепроверить и обновить.
- Ориентиры «Bloomberg / Linear» заменить на целевое состояние: монохром, читаемый график, один акцент.
- Размеры h-6 и 10px для всего интерфейса слишком жёсткие. Оставить 11px для подписей, 12px для чисел, плотность 24–28px только для таблиц.

## Предлагаемый порядок работ

1. Токены и палитра: один акцент, нейтральная шкала, 3 пресета.
2. Верхняя панель: разнести по уровням, убрать дубли, вынести аварийную кнопку.
3. Тулбар графика: единый стиль кнопок, один цвет для активного состояния.
4. Оверлеи и подписи уровней: группировка, лимит подписей, компактные чипы для ордеров.
5. Типографика и контраст.
6. Баги, язык интерфейса, иконки только lucide.
