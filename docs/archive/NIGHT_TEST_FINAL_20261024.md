## Проблемы, выявленные прогоном (приоритет)

### 🔴 P0 — баги
1. **Live-раннер шлёт ордера по ВСЕМУ вотчлисту.** При старте 08:29 выставил
   685 ENTRY-ордеров: 50 попыток × 13 символов + BTC. Раннер настроен на BTCUSDT,
   но сканер сигналов перебирает вотчлист. Только BTC реально отработал.
   → ограничить сигналы символом раннера.
2. **ema_trend: лимитный вход не по рынку.** Ночной сигнал BNB (cross up): BUY LIMIT
   выше рынка (~+0.19%) → за 3 часа не исполнился, сигнал сгорел. Дневной SELL LIMIT
   выше рынка — исполнился мгновенно (для шорта это «в рынок»). Логика цены входа
   асимметрична и теряет лонг-сигналы в росте.

### 🟡 P1 — качество/параметры
3. **ema_cross режет 66% оценок** (4137/6263) — на 5m в боковике пересечений EMA 20/50
   почти нет; за 13,5 часов 14 пар дали 2 реальных входа. Нужен разговор о параметрах
   (периоды EMA, дополнительный триггер входа) — не менять молча.
4. **minimum_turnover** у LINK/DOGE ночью (7–13k < 50k) — ночная ликвидность мелкая;
   кандидат на адаптивный порог по времени суток.
5. **preflight_valid=False** у работающих сессий после старта (TTL preflight) —
   косметика статуса, путает при диагностике.

### 🟢 P2 — техдолг

7. **Транзиентный фейл BLOCKING UI smoke в gate** (2 случая, не воспроизводится).
8. **Free-модели OpenRouter нестабильны** (429/таймауты/пустые) — для боевого AI
