# SignalScript Design Guide & Tokens

## 1. Архитектурные принципы
- **Единый источник правды (Single Source of Truth)**: Все CSS-переменные определены в `src/styles/tokens.css` и подключены в `src/index.css` через Tailwind v4 `@theme inline`.
- **4 темы терминала**:
  1. `night` (по умолчанию): Спокойная темно-графитовая палитра, низкая утомляемость глаз, акцент — приглушенный циан.
  2. `neon`: Высококонтрастная глубокая черная тема для скальпинга с кислотными акцентами и заметными ликвидациями.
  3. `mono`: Монохромная шкала серых оттенков с акцентом цвета янтаря (amber/gold), чистый институциональный стиль.
  4. `day`: Мягкая светлая тема без слепящего белого (warm slate/grey), строгий контраст >= 4.5:1.
  - Обратная совместимость: селекторы `tealstreet`, `tiger`, `bloomberg`, `graphite`, `signal`, `cyan_night` сохранены как алиасы.
- **Производительность 60 FPS**:
  - Никаких вызовов `getComputedStyle` внутри циклов `requestAnimationFrame` или обработчиков сокетов.
  - `themeBridge` считывает цвета токенов один раз при смене темы и предоставляет плоский JS-объект для KLineCharts и Canvas (DOM, Footprint, Heatmap).

## 2. Размеры и плотность (Dense FinTech)
- Текст подписей: `--font-size-label: 11px` (ничего мельче 11px).
- Основной текст: `--font-size-body: 12px`.
- Числа, цены, объемы: `--font-size-num: 12px` (строго `tabular-nums` и `font-mono`).
- Заголовки виджетов: `--font-size-title: 13px`.
- Высота строк таблиц: `--row-h-table: 26px`.
- Высота контролов: компактные `--control-h-sm: 24px`, стандартные `--control-h-md: 28px`.

## 3. Правило одного акцента
- Кнопки и тулбары по умолчанию нейтральные (ghost / subtle).
- Цвет появляется только у активного переключателя (data-active / aria-pressed) или у рыночных данных (`text-bull`, `text-bear`, `text-density-wall`).
